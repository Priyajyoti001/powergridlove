# Powergridlove

build a website which looks professional... and on the topic of EV charging stations, availability, potential charging stations which can be built, crowd on charging stations, an interactive map which features both 2d and 3d view to analyse charging stations..

key features to be noted and added:

1.A dashboard consisting of data about total charging station all over india, currently available charging stations, Charging stations under construction.

2.In the same page as the dashboard, make some pie charts and bar graphs to feature crowd intensity vs working hours, top states with charging stations, etc,

3.Make dedicated page upon analytics which must include graphs and more pictorial data on
a) EV sales projected with actual as per FY upto 2030

b) EV vehicles share on indian Roads through a pie chart

c) EV registration growth

d) EV industry growth

e) State wise ev growth in india..

4.An interactive Map with both 2d and 3d view which will show charging stations all over india. and a panel for the user to quick search ev stations near their own location using both location permission and by manual entry of city and area.. Map interactions must be smooth and fluid..

5.an Ai model inbuilt on the website to help the user with queries..

6.finally a page to include various reports available online related to this project..

7.Website name should be Power Grid.
8. a proper professional looking login page with login credentials card floating in center with a matching dark background.
